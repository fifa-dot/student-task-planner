ДИПЛОМНЫЙ ПРОЕКТ: Учебный планировщик

Файлы:
- app.py — серверная логика сайта на Python и Flask
- templates/index.html — главная страница
- templates/edit.html — страница редактирования
- static/style.css — оформление сайта
- tasks.db — база данных создаётся автоматически при первом запуске

Как запустить:
1. Откройте папку проекта в Visual Studio Code.
2. Откройте Terminal -> New Terminal.
3. Выполните: python -m pip install flask
4. Выполните: python app.py
5. Откройте в браузере: http://127.0.0.1:5000

Пока сайт работает, не закрывайте терминал. Чтобы остановить сайт, нажмите Ctrl+C в терминале.

Все задания сохраняются в локальном файле tasks.db в папке проекта.
